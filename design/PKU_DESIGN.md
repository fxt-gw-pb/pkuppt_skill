# PKU_DESIGN.md — PKU 红色学术汇报设计契约

这不是泛化品牌系统，而是 **`left-sidebar` 与 `top-nav` 两套既有 PKU 红色 PPT 模板** 的设计契约。生成、校验、修复、返修都必须遵守它。目标只有一个：让产物看起来"就是这两套北大红学术模板"，不多不少。

## 1. Visual Theme & Atmosphere
- 北京大学红色（北大红）学术汇报 / 论文答辩风格。
- 简洁、克制、正式；大面积白色留白；信息层级清楚。
- **不炫技**：不追求"现代感/科技感/高级感"，不重新设计风格。

## 2. Color Palette & Roles
| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 主色 北大红 | `#9E0000` | 侧栏/导航/标题/Part 编号/强调/表头/项目符号 |
| 封面深红 | `#9B0000` | 封面/Part/结尾的红色横条 |
| 金（仅 top-nav） | `#CFAF6A` | 目录编号块、装饰短线 |
| 正文墨 | `#262626` / `#222222` | 正文与小标题 |
| 辅助灰 | `#BFBFBF`（细线）`#A6A6A6`（页码）`#F0F0F0`（浅底） | 分隔线/页码/弱化背景 |
| 背景 | `#FFFFFF` | 内容页背景 |

强调=北大红或加粗深色二选一，不得引入第三种强调色，不得用荧光色。

## 3. Typography Rules
- 中文优先 **微软雅黑 / Microsoft YaHei**，英文 **Arial**；衬线（宋体）仅用于 top-nav 校徽锁定组合。
- 字号区间（设计空间 px；左侧栏≈上方栏×1.5）：
  - 页面标题：left ≥ 39（默认 56），top ≥ 26（默认 28）。
  - 正文：left 24–34（默认按内容自适应），top 16–20。
  - 图注：left ≥ 18（默认 24），top ≥ 12（默认 13）。
- **正文过多优先拆页，不要无限缩小字体**；正文不得低于模板下限（left 24 / top 16）。

## 4. Layout Principles
- 16:9 固定设计空间：left `1920×1080`，top `1280×720`。
- 安全区（正文只能落在安全区内，绝不覆盖其它元素）：
  - **标题安全区**：页面标题/小标题区。
  - **导航安全区**：left 左侧 306px 竖栏 / top 顶部 62px 横栏。
  - **内容安全区**：left `x338 y240 w1492 h750`；top 有红条 `x101 y320 w1078 h336`，无红条 `x101 y170 w1078 h486`。
  - **图片安全区**：等于内容安全区（含图注预留）。
  - **页码安全区**：右下角，正文不得压占。
- 内容在安全区内用 flex/grid 流式排布——天然不重叠。

## 5. Components
`cover`（封面，标题居于红条内、自动适配字号）·`contents`（目录：left 用 Part N，top 用 01/02 金块）·`part`（仅 top：Part.0N + 中/英标题）·`content`（正文页：导航高亮 + 标题 + 流式正文）·`ending`（致谢）·`figure`（图容器 + 绑定图注）·`table`（红表头 + 斑马纹）·`navigation`（数据驱动、当前高亮、随数量自适应）·`caption`（小于正文但清晰）。

## 6. Do's and Don'ts
**Do**：保持两套 PKU 模板原始风格；纯色扁平；留白充足；标题/正文/图注层级分明；导航数量随大纲自适应。
**Don't**：现代卡片化过度、圆角过大；渐变、阴影、3D、科技感线条、复杂动画；乱加 emoji / 图标 / 装饰；为"高级感"破坏原模板；改成另一种风格；把正文压到不可读或贴边漂浮。

## 7. Agent Prompt Guide（每次生成前的固定顺序）
1. **先读大纲**，理解章节/页面/图表/加粗，不擅自改内容。
2. **先定模板**（用户指定优先，否则按章节数）。
3. **再生成 `deckConfig`**（解析+布局+拆页+选字号）。
4. **再渲染** HTML（静态预渲染，单一数据源）。
5. **再校验**（`validate_layout`）。
6. **再修复**（`auto_repair`，先布局后字号，不破坏内容与风格）。
7. **最后交付**（导出 PDF + 打包 + 写报告/历史）。

> 校验与修复都以本文件与 `references/*` 为判据；任何"看起来更高级"的改动若违反本契约，一律视为风格漂移并撤销。
