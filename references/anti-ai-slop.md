# references/anti-ai-slop.md — 别把它做成"AI 味"模板

目标：产物看起来**就是这两套北大红学术模板**，像人精心排过，而不是"AI 生成感"。`critique_deck.js` 会扫描并报告下列违规为 `template_drift`。

## 不要做
- **不要乱加渐变**：`linear/radial/conic-gradient` 一律禁止，用纯色。
- **不要乱加阴影**：内容元素禁止 `box-shadow`/`text-shadow`（屏幕控制条除外）。
- **不要 3D / 科技感**：禁止 `perspective/rotate3d/translateZ`、发光线条、霓虹描边。
- **不要乱加 emoji**：幻灯片正文禁止 emoji。
- **不要乱加图标**：不堆装饰性 icon、不加无意义小图形。
- **不要过度装饰**：不要圆角过大的"现代卡片"、不要花哨分隔符、不要复杂动画。
- **不要为"高级感"破坏原模板**：不改主色、不改版式骨架、不改字族。
- **不要重新设计成另一种风格**：保持 PKU 红学术风格不变。
- **不要让内容漂浮 / 拥挤 / 错位**：用安全区 + 流式排布，留白充足，层级清楚。

## 要做
- 纯色、扁平、克制；北大红 + 白 + 少量墨/灰（top 另有金色编号）。
- 充足留白；标题/正文/图注层级分明；左对齐正文。
- 卡片用扁平边框 + 顶部红色细条（无阴影、无大圆角）。
- 强调只用北大红或加粗深色，二选一。

## 自检
- "这页放进原 PPT 里，会不会显得格格不入？" 若会，就是 slop。
- "有没有为了好看牺牲可读性 / 牺牲对大纲的忠实？" 若有，撤销。
- critique 报 `template_drift / emoji / shadow / gradient` → 必须移除装饰回到契约。
