# references/layout.md — PKU PPT 版式规则

## 设计空间与缩放
- 16:9 固定设计空间：left `1920×1080`，top `1280×720`。所有元素按 px 绝对定位，运行时整体 `transform: scale()` 等比缩放居中（letterbox），打印时一页一片。

## 内容安全区（正文唯一可落区）
- left：`{x:338, y:240, w:1492, h:750}`。
- top：有红条副标题 `{x:101, y:320, w:1078, h:336}`；无红条 `{x:101, y:170, w:1078, h:486}`（默认无红条，正文区更大）。
- 安全区之外为保留区：导航、标题、页码、（top 的）红条，正文一律不得覆盖。

## 排布原则（为什么不会重叠）
渲染器在安全区放置**一个固定尺寸容器**，容器内用 flex/grid **流式排布**。流式盒子不会相互重叠，`object-fit:contain` 不会变形，`max-width/height:100%` 不会撑破。于是唯一风险只剩"流式内容比容器更高"——由 `scripts/lib/measure.js` 确定性估算并校验。

## 布局类型与自动选择
| 布局 | 适用 | 自动触发 |
| --- | --- | --- |
| `text-only` | 纯文字（背景/意义/结论） | 无图无表 |
| `image-full` | 单张大图（流程/框架/模型） | 仅图无正文 |
| `text-image-right` | 左文右图（说明/结果） | 1 张竖图/方图 + 文 |
| `image-text-right` | 左图右文 | 显式指定 |
| `text-image-bottom` | 上文下图（宽图） | 1 张宽图 + 文 / 放大图 |
| `three-points` | 三点式（贡献/创新点） | 单列表恰 3 短项 |
| `four-cards` | 四模块 | 单列表恰 4 短项 |
| `timeline` | 步骤流程 | 显式指定 |
| `table` | 表格页 | 含 Markdown 表格 |
| `comparison` | 左右对比 | 显式指定 |
| `image-grid-2 / image-grid` | 2 / 3–4 图网格 | 2 / 3–4 张图 |

## 长文本拆页
- 单段落若单独都放不下 → 按句子（。！？；）切分重组为多段。
- 顺序贪心打包：依次累加块，放不下就开新页（保序）；续页标题加"（续）/（续N）"。
- 选字号：对每页选**能放下的最大字号**；达下限仍超 → 继续拆页。

## 多图布局
- 1 图：按形状选 right/bottom/full。2 图：`image-grid-2`。3–4 图：两列网格。
- 有正文时图上限 2，无正文时上限 4；超出自动拆为多页（保序）。

## 表格布局
- 红色表头、斑马纹、细边框。行数超出安全区 → `auto_repair` 按"每页可容行数"拆为多页并加"（续）"，**不丢行**。列过多 → 标记 `table_too_wide`（可减小字号）。

## 导航版式
- left：竖向堆叠，字号/间距随章节数自适应；章节多仍保持风格。
- top：横向均分，字号随章节数自适应；过长允许换行；不溢出页面边界。
